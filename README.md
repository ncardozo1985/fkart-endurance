#  FKART Endurance Racing Monitor

**Force Kart Racing**  Sistema de monitoramento para corridas de kart endurance.

##  App ao vivo
https://fkart-endurance.web.app

##  Funcionalidades
- **Ranking**  Classificao geral + por categoria, paradas P6'/P10'
- **Comparativo**  Top 10 grfico de desempenho
- **Mapa**  Traado animado com posio do kart
- **Traados**  Biblioteca de 31 traados do KGV
- **Pilotos**  Cadastro de pilotos com karts e caractersticas
- **Box**  Controle de status dos karts em tempo real
- **Projeo**  Classificao projetada ao fim da corrida
- **Config**  Painel de configurao da corrida

##  Tecnologias
- HTML/CSS/JS puro (single file)
- Firebase Hosting
- Race Monitor API (timing ao vivo)

##  Kartdromo
Granja Viana  Cotia, SP (KGV)
